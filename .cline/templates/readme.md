## Getting Started

Explain the high‑level workflow:

1. **Plan** – Use the Planner Agent to define requirements.
2. **Generate** – Agents create features, page objects, components, etc.
3. **Review** – Human approval gates.
4. **Execute** – Tests run via Playwright and report to Allure.
5. **Maintain** – Agents refactor and update automatically.

## Prerequisites

- **Node.js** (>= 18)
- **npm** (or **yarn**, **pnpm**)
- **Git**
- **VS Code** with the **Cline** extension (optional but recommended)

## Installation

```bash
git clone <repository-url>
cd <project-folder>
npm ci
# Install Husky hooks
npx husky install
```

## Running Tests

```bash
# Run all Playwright tests
npm run test

# Run a specific feature file
npm run test -- tests/<feature>.feature

# Generate Allure report
npm run allure:serve
```
